---
name: cairn
description: Track multi-PR or multi-step work on a cairn trail. Use when work spans several PRs or repos, or has steps that aren't PRs (a release, a feature flag), when the user mentions a trail or cairn, or when asked to set up cairn.
---

Run `cairn skills get cairn` and follow the guide it prints. It is built into the cairn
binary, so it always matches the installed version. To install or fix cairn, run
`cairn skills get setup` instead.
